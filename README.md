Student Registration & Contact Intelligence System

Project Description

This project is developed using Python to manage student registration and contact details.

Objectives

- Register student details.
- Validate phone numbers and email addresses.
- Search student records.
- Update and delete student records.
- Generate contact analytics.

Technologies Used

- Python 3
- CSV
- Python IDLE

Project Files

- validator.py – Validates student details.
- loader.py – Loads and saves contact records.
- analytics.py – Generates contact statistics.
- main.py – Main program with menu options.
- contacts.csv – Stores student contact details.
- students_clean.csv – Stores valid student records.
- proof – Contains project testing evidence.

How to Run

1. Open the project folder.
2. Open Python IDLE.
3. Open main.py.
4. Press F5 to run the program.

Conclusion

This project helps manage student information using Python functions, file handling, validation and data analysis.
