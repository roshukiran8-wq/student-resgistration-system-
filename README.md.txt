# Student Registration & Contact Intelligence System

## Project Description
This project is developed using Python.
It manages student registration and contact information.

## Features
1. View All Students
2. Search Student
3. Register Student
4. Update Student
5. Delete Student
6. Analytics Report
7. Exit

## Python Files
- validator.py – Validates student details.
- loader.py – Loads and cleans CSV data.
- analytics.py – Displays data analytics.
- main.py – Runs the menu-driven system.

## Input File
- contacts.csv

## Output File
- students_clean.csv

## How to Run
1. Open Python IDLE.
2. Open loader.py and press F5.
3. Open main.py and press F5.
4. Select an option from the menu.
